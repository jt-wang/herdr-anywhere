隐私

Herdr Anywhere 把你的手机和配对过的电脑连起来。我们不运营任何服务器，也看不到两者之间传的内容。

  • 你的终端、agent 和你输入的内容，经过你在电脑上运行的 herdr-anywhere companion，只在手机和你自己的电脑之间传输。
  • 通过 Tailcat（Tailscale 的开源隧道，在 app 和电脑上运行）配对时，连接用 WireGuard 端到端加密。Tailcat 的公共中继服务器帮两台设备找到对方，直连不通时替它们转发流量。中继能看到设备密钥和 IP 地址，看不到你的终端。app 从 tailcat.dev 获取中继列表。
  • 改用局域网配对时，连接不加密，同一网络里的任何人都能读到。
  • 在手机上，app 保存与电脑的配对、你的设置，以及上次看到的空间和 agent。在「设置」里点「忘记这台电脑」就会删除配对。
  • 在电脑上，companion 保存已配对手机的列表（名称和每台最后连接的时间）以及连接日志。配对码和手机令牌只以哈希形式保存。
  • companion 每天向 GitHub 查询一次新版本，前提是你在 app 里同意过，或者打开了自动更新；你或已配对的手机要求时，它会下载新版本，打开了自动更新时也会自己下载。app 只在你点「下载」获取新版本时访问 GitHub。GitHub 能看到发出请求的设备的 IP 地址。
  • 摄像头只用来扫配对二维码，不保存任何图片。
  • 「试一试」在 app 里使用示例数据，不连接任何地方。
  • app 里没有统计分析、没有广告标识符，也没有会往外发数据的第三方 SDK。
  • 在 TestFlight 测试版里，Apple 会收集崩溃报告、使用数据和你选择发送的反馈，并按照 Apple 的 TestFlight 条款与我们共享。

有问题请到 GitHub 上提。
