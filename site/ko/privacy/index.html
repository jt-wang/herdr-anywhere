개인정보 보호

Herdr Anywhere는 휴대폰과 페어링한 컴퓨터를 연결해요. 저희는 서버를 운영하지 않으며, 둘 사이에 오가는 내용을 볼 수 없어요.

  • 터미널, 에이전트, 그리고 거기에 입력한 내용은 컴퓨터에서 실행하는 herdr-anywhere companion을 거쳐 휴대폰과 내 컴퓨터 사이에서만 오가요.
  • Tailcat(Tailscale의 오픈 소스 터널로, 앱과 컴퓨터에서 실행돼요)으로 페어링하면 연결은 WireGuard로 종단 간 암호화돼요. Tailcat의 공개 릴레이 서버는 두 기기가 서로를 찾도록 돕고, 직접 연결할 수 없을 때 트래픽을 전달해요. 릴레이가 볼 수 있는 것은 기기 키와 IP 주소뿐이고, 터미널 내용은 볼 수 없어요. 앱은 릴레이 목록을 tailcat.dev에서 받아요.
  • 로컬 네트워크로 페어링하면 연결이 암호화되지 않아서, 같은 네트워크에 있는 누구나 읽을 수 있어요.
  • 휴대폰에서는 앱이 컴퓨터와의 페어링, 설정, 마지막으로 본 스페이스와 에이전트를 저장해요. 설정의 '이 컴퓨터 지우기'로 페어링을 지울 수 있어요.
  • 컴퓨터에서는 companion이 페어링한 휴대폰 목록(이름과 각각 마지막으로 연결한 시각)과 연결 기록을 저장해요. 페어링 코드와 휴대폰 토큰은 해시로만 저장해요.
  • companion은 앱에서 허용했거나 자동 업데이트를 켠 경우에만 하루에 한 번 GitHub에서 새 릴리스를 확인해요. 다운로드는 사용자나 페어링한 휴대폰이 요청할 때, 또는 자동 업데이트가 켜져 있으면 스스로 해요. 앱은 '다운로드'를 눌러 새 버전을 받을 때만 GitHub에 접속해요. GitHub는 요청한 기기의 IP 주소를 볼 수 있어요.
  • 카메라는 페어링 QR 코드를 스캔할 때만 쓰고, 사진은 저장하지 않아요.
  • '체험하기'는 앱 안의 샘플 데이터로 동작하고, 아무 데도 연결하지 않아요.
  • 앱에는 분석 도구, 광고 식별자, 외부로 데이터를 보내는 서드파티 SDK가 없어요.
  • TestFlight 베타에서는 Apple이 충돌 보고서, 사용 데이터, 사용자가 보내기로 한 피드백을 수집하고, Apple의 TestFlight 약관에 따라 저희와 공유해요.

궁금한 점은 GitHub에 남겨 주세요.
